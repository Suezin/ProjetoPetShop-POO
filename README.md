# Gerenciador de PetShop em Java

---

## Este projeto é um estudo de java que contém um gerenciador de usuarios e atendimentos em java

## O que ele faz ?

Este projeto é focado em uma interface de um sistema de uma PetShop, que apresenta funções de gestão de usuários e gestão de pedidos para atender na PetShop.

## Tecnologias 

Este projeto tem as seguintes tecnologias :

-java
-JavaSwing
-MySql

## Como Usar 

1. Clone o repositório na sua máquina
   
```
git clone https://github.com/Suezin/ProjetoPetShop-POO.git
```

2. Acesse a pasta do projeto e inicie a sua Ferramenta de código(de preferência o NetBeans) no diretório

```
cd /[Diretório do projeto]/ProjetoPetShop-POO/src/petshop
```

3. inicie um banco local na sua máquina utilizando o arquivo dumpProjetoFinal.sql

4. Troque as seguintes variáveis do arquivo GerenciadorConexao.java para os dados do seu banco de dados local:

```
private static final String URL = "jdbc:mysql://127.0.0.1:3306/dbpetshop";
private static final String USER = "root";
private static final String PASSWORD = "";
```
 
5. Inicie a classe principal PetShop.java
