# Gerenciador de PetShop em Java

## Este projeto é um estudo de java que contém um gerenciador de usuarios e atendimentos a serem feitos em java, tudo isso em uma interface feita com javaSwing

## O que ele realmene faz ?

Este projeto é focado em uma interface de um sistema de uma PetShop, que apresenta funções de gestão de usuários e gestão de pedidos para atender na PetShop.

## Tecnologias 

Este projeto foi desenvolvido totalmente em java, a interface foi feita em JavaSwing e o banco de dados feito em MySql.

## Como Usar 

1º Clone o repositório na sua máquina 
git clone https://github.com/Suezin/ProjetoPetShop-POO.git

2º Acesse a pasta do projeto e inicie a sua Ferramenta de código(de preferência o NetBeans) no diretório
cd /[Diretório do projeto]/ProjetoPetShop-POO/src/petshop

3º inicie um banco local na sua máquina utilizando o arquivo dumpProjetoFinal.sql

4º Troque as seguintes variáveis do arquivo GerenciadorConexao.java para os dados do seu banco de dados local

   private static final String URL = "jdbc:mysql://127.0.0.1:3306/dbpetshop";
    private static final String USER = "root";
    private static final String PASSWORD = "";
    
5º Inicie a classe principal PetShop.java
